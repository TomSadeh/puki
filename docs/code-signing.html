מה נחתםWhat is signed

Puki.exe, המוח של פוקי למחשב עם Windows. הוא נבנה ב-GitHub Actions ישירות מהקוד במאגר TomSadeh/puki, מתג הגרסה (תהליך הבנייה), ונחתם רק אחרי שבקשת החתימה אושרה ידנית. הקובץ החתום מצורף לגרסה ב-GitHub Releases.

Puki.exe, Puki's brain for Windows PCs. It is built by GitHub Actions directly from the source in TomSadeh/puki at the release's tag (the build workflow), and signed only after an approver confirms the signing request. The signed file is attached to the release on GitHub Releases.

האפליקציה לאנדרואיד נחתמת במפתח של פוקי עצמו, ועדכוני המוח במחשב (install.py --update) נחתמים במפתח העדכונים של פוקי ונבדקים לפני התקנה.

The Android app is signed with Puki's own key, and the PC brain's updates (install.py --update) with Puki's update key, checked before anything is installed.

פרטיותPrivacy policy

התוכנה הזו לא מעבירה שום מידע למערכות אחרות ברשת, אלא אם המשתמש או מי שמתקין או מפעיל אותה ביקש זאת במפורש.

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

בפועל: ההתקנה מורידה את המודלים והכלים (כל קובץ נבדק מול SHA-256 קבוע מראש) מ-GitHub ומ-Hugging Face; עדכון בודק את GitHub Releases רק כשמבקשים אותו; והמוח מדבר רק עם הטאבלט של המשפחה ברשת הביתית. הפרטים במדיניות הפרטיות.

In practice: setup downloads the models and tools (every file checked against a SHA-256 fixed in advance) from GitHub and Hugging Face; an update checks GitHub Releases only when asked to; and the brain talks only to the family's tablet on the home network. The details are in the privacy policy.
